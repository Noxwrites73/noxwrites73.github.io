Sources, file by file

The other way round from receipts.txt, which is organised by claim. This page is organised by file: everything in sources/, what it was fetched for, and what it can carry. Copies are as served, unedited except for the .html suffix. A copy proves a page said something on the date in its folder name. It proves nothing about today and nothing about whether anyone read the text built on it.

Two files belong to the site rather than to this folder: the IndexNow key 8f4b2c6d9e1a4f73b05c2d8e6a1f4c93.txt at the host root, which is exactly those 32 bytes, and the Street View images, which are kept in assets/ so the picture does not depend on a Google URL staying alive.

Checked 20 November 2026. Every row below was read against its own file, not against my notes about the file. What the check found is in the rows themselves. Three of them changed: the Clarkesworld row said the page carries no rate (it does, 15¢ a word), the three Apex files were described as the same bytes (same size, different request ids), and the Lone Mountain row carried one fact the article does not say. One file had no row at all, strange-home.html, and now has one.

A limit that runs through both folders: a saved page shows what came back, not what the status code was. ls.html proves a page said “Page not found”; the 404 is in receipts.txt, because a copy of a 404 body and a copy of a 200 that says the same thing look identical here. Same for the 500s and the 403.
